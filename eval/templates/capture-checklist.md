# Capture checklist

Use this one-page sheet for each eval unit.

## Unit metadata
- [ ] Unit ID: `UNIT-EVAL-###`
- [ ] Order ID recorded
- [ ] SKU / ASIN recorded
- [ ] 2 to 3 photos captured
- [ ] Photos show the same item and same SKU

## Photo quality checks
- [ ] Front view captured
- [ ] Side or angle view captured
- [ ] Close-up accessory / damage view captured when needed
- [ ] Lighting noted as `good` or `poor`
- [ ] Angle noted as `standard` or `oblique`
- [ ] Blur noted as `none` or `slight`
- [ ] Ambiguity noted as `clear` or `genuinely_ambiguous`

## Scenario and context
- [ ] Scenario code(s) selected from official list
- [ ] Product seen in dev? `yes` / `no`
- [ ] Category seen in dev? `yes` / `no`
- [ ] Notes recorded for unusual evidence or ambiguity

## Safety
- [ ] Not used in prompt tuning or dev debugging
- [ ] Not opened in a way that would violate eval secrecy
