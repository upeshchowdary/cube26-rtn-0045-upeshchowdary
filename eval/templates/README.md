# Eval templates

This folder contains human-facing blanks only. No sealed data or labels are stored here.

Files in this folder:
- `orders.csv`: order metadata template for a unit
- `conditions.csv`: capture-time condition metadata template
- `labeller_a.csv`: first labeller template
- `labeller_b.csv`: second labeller template
- `capture-checklist.md`: printable capture checklist
- `labelling-sheet.md`: printable labelling sheet

Do not add data rows to these templates until a human is ready to fill them in.
